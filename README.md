## Active Learning Management (ALM) Client-Server Cipher

This project is a Python client-server application that demonstrates three encryption algorithms:
1. Caesar Cipher
2. Playfair Cipher
3. Simplified Data Encryption Standard (SDES)

It supports textual messaging as well as byte-level file transfer using SDES.
